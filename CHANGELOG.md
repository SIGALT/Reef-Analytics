# Changelog

## [0.7.0-alpha] - 2026-09-05

### Added
- Reef Analytics project name
- Native synthetic 3D coral geometry
- Interactive model rotation
- Df3D approximation using 3D box-counting
- Surface area estimation
- Colony volume estimation
- Projected area and height
- Shelter volume
- T0 vs T1 comparison
- CSV, PNG, and PLY export
- Responsive PWA
- Species presets for *Acropora palmata* and *Pocillopora damicornis*

### Known limitations
- Geometry is not yet watertight
- Branch overlap is not subtracted from area/volume
- Df3D is computed from sampled synthetic surface points
- Structural stress is conceptual rather than empirically calibrated
